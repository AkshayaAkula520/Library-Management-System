# 📚 Library Management System

A web-based Library Management System developed using Flask, MySQL, HTML, CSS, and JavaScript.

## 🚀 Features

- 📊 Dashboard with library statistics
- 📚 Book management
- ➕ Add books
- ✏️ Edit books
- 🗑️ Delete books
- 🔍 Search books by title or author
- 🏷️ Filter books by category
- 👨‍🎓 Student management
- ➕ Add students
- ✏️ Edit students
- 🗑️ Delete students
- 📖 Issue books
- 🔄 Return books
- 📋 Borrowing records
- 📈 Recent borrowing information
- 🔐 Protection against deleting books/students with borrowing records

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
